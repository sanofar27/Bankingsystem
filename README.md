Problem Statement
Develop a console-based Banking Management System using Java to manage customers and their bank accounts. The system should allow users to add customers, open savings or current accounts, deposit money, withdraw money, apply for loans, and display customer and account details. It should validate transactions and prevent withdrawals beyond the permitted balance and overdraft limit.

Features
1. Add a new customer.
2. Open a Savings Account or Current Account.
3. Deposit money into an account.
4. Withdraw money from an account.
5. Submit a loan application.
6. Display account details and balance.
7. Display all registered customers.
8. Validate inputs and transaction amounts.
